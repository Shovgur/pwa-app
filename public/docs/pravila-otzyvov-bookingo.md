# Правила отзывов BookinGo

Документ-черновик для юридического согласования перед go-live (этап 4).
После утверждения заменить на подписанный PDF `pravila-otzyvov-bookingo.pdf`.

## 1. Общее
- Отзыв можно оставить после визита, в течение **7 дней**.
- **Один отзыв на бронь** с каждой стороны (клиент→площадка и менеджер→клиент).

## 2. Отзывы о площадке (публичные)
- Оценка 1–5, теги, текст.
- Текст проходит лёгкую премодерацию (контакты, мат, спам).
- Опубликованные отзывы видны всем посетителям сайта.
- Менеджер/владелец площадки может оставить один ответ.

## 3. Отзывы о клиенте (непубличные)
- Доступны: самому клиенту (без ФИО автора) и сотрудникам того же `partner_id`.
- Другие партнёры и гости сайта отзывы о клиенте **не видят**.
- Бейдж «Внимание» может учитывать сетевой сигнал за 12 месяцев без раскрытия чужих текстов.

## 4. Запрещено
- Оскорбления, угрозы, персональные данные третьих лиц, реклама.
- Оспаривание отзывов в продукте v1 не предусмотрено — только модерация.

## 5. Согласие
Оставляя отзыв, пользователь соглашается с этими правилами и Политикой конфиденциальности BookinGo.
